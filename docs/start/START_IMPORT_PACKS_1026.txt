Импортируй в игру модели пакетов, сделанных после заказа forest_start (пост на въезде в запретную зону), и расставь их по местам. Проект F:\ClaudeGames\snow\Snow. Бункер под озером сюда не входит — для него отдельный промпт START_BUNKER_LOCATION.txt.

Источники: пакеты в F:\ClaudeGames\snow\source\assets\<пакет> (blend, json-контракт, текстуры tex\, лист, рендеры), справочники — F:\ClaudeGames\snow\docs\gdd\<ИМЯ>_CONTRACT.md. В контрактах все позиции, оси и коллайдеры даны и в кадре Unity (поля *Unity), в кадре своего корня.

Как импортировать — по образцу forest_start и forest_hut_yard:
- FBX — скриптом по образцу tools\forest_start\export_fbx.py: корень в нуле, forward −Z, up Y, Apply Transform, без COL_ / HIT_;
- данные — по образцу tools\forest_start\make_unity_data.py → <Пакет>_Unity.json в папке пакета;
- префабы — новыми Pack в StartPropsBuilder (или тем же способом): текстуры point, без мипмапов, без сжатия; материалы URP Lit, как у кита; стёкла ламп в префабе — _Off, горящие — отдельными материалами; BoxCollider по colliders контракта; точки (sockets) — пустые дочерние; детали IX_* и подвижные части — отдельными объектами с пивотом по контракту, в позе покоя, без интерактива (как у forest_start: интерактив — отдельной задачей); свет — по *_lights.json, выключен; повторный запуск переписывает те же ассеты (те же GUID);
- расстановка — шагами сборки Forest по образцу ForestStartDressStep: данные в Assets\Snow\Levels\Forest\*.json, каждая группа — своим корнем, второй запуск даёт тот же результат, карту вне своих групп не трогать.
