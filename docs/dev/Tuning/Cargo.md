## Захват (GRAB-01) — `Runtime/Cargo/GrabMath.cs`

| Параметр | Значение | Почему |
|---|---|---|
| Жёсткость руки | 2000 Н/м | 20 кг провисают на 0.1 м — заметно, но держит |
| Демпфирование | 150 Н·с/м | по относительной скорости точки и цели, чтобы в едущей машине не тормозить предмет |
| Сила одного игрока | 400 Н | один не поднимет 60 кг (588 Н), двое поднимут (800 Н) — AT-08 |

| Цель руки устаревает | 0.5 с | потеря пакетов или замерший клиент не держат предмет вечно |
