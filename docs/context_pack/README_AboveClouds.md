# Над облаками — финал

Здесь нет тумана: ясное тёмно-синее небо, низкое послеполуденное солнце (~24° над горизонтом, с юго-запада) и сплошное море кучевых облаков внизу (верх на отметке ≈0). Из облаков поднимаются заснеженные гранитные рога высотой до +335 м: острые рёбра-арэты, кулуары со снегом, скальные гребни. Вдали, до 7 км, торчат из облаков дальние пики и башни кучевых облаков. К горизонту лёгкая голубая дымка. Между пиками стоит на коленях единственный неподнятый гигант: колени на скрытой земле на −230 м, над облаками видны череп (поднят, смотрит прямо на аэродром), ключицы, верх грудной клетки и плечи. Кости цвета старой слоновой кости, чтобы читались на снегу. Попасть сюда можно только на самолёте с Sky Island.

## Что внутри
| Папка | Содержимое |
|---|---|
| `Models/` | `Clouds_Terrain`: пики, рельеф обрезан ниже облаков. `Clouds_Sea`: море облаков с куполами, без коллайдера. `Clouds_FarPeaks`: дальние пики, без коллайдера. `Cumulus_0..2`: башни кучевых облаков на горизонте, без коллайдера. Высокогорный аэродром: наклонная ВПП на отроге западного массива (асфальт, разметка, огни), перрон, маленький ангар, домик, ветроуказатель, топливная ёмкость. Станция на уступе северного пика: домики, мачта с красными огнями, флаг. Подвесной мост ~90 м с уступа на правое плечо гиганта, площадка на ключице. Валуны |
| `Textures/` | Макро-текстура пиков (снег на полках и в кулуарах, скальные рёбра, полоса ВПП со снежными валами), атлас дальних пиков, текстуры облаков `T_CloudSea_A/N` (тайл 400 м), `LUT/AboveClouds_LUT32.png`; с обновления 8 — PSX-текстуры `*_px.png` и маски `*_M_px.png` по рецепту самолёта (из общих текстур ядра, своими копиями) |
| `Data/` | `AboveClouds_Layout.json`, `AboveClouds_Materials.json`, `AboveClouds_Look.json` |
| `Previews/` | Эталонные рендеры (1280×720) |

Общие вещи (скрипты, шейдеры, скелет гиганта, общие текстуры) лежат в пакете Sky Island (`Assets/SkyIsland`).

## Установка
1. Обновить ядро Sky Island: импортировать пакеты `SkyIsland_Update_*.unitypackage`.
2. Импортировать все части `AboveClouds_*.unitypackage` (ставятся в `Assets/Locations/AboveClouds`).
3. `Tools → Locations → Location Builder` → `AboveClouds` → **Build**, или `-executeMethod SkyIsland.EditorTools.SkyIslandBuilder.BuildLocationFromCommandLine -location AboveClouds`.
4. Проверка: `CaptureLocationFromCommandLine -location AboveClouds` → `SkyIslandCaptures/AboveClouds/` против `Previews/AboveClouds_*.jpg`.

## Точки обзора
Approach (заход на посадку: полоса на отроге ведёт к гиганту), Altiport (перрон у ангара, за торцом ВПП гигант), Station, Bridge, GiantFace (лицо гиганта), Shoulder (с площадки на ключице вниз по груди гиганта, над морем облаков), CloudSea (низко над облаками с юга), HighPeak (с уступа высокого пика сверху на гиганта), Aerial.

## Игровые зацепки
- **Посадка**: полоса 30 × ~390 м с уклоном вверх ~10 %. Садиться против уклона на восток-северо-восток, прямо на гиганта: он смотрит на полосу. В начале полосы зелёные огни, в конце красные. Нижний торец в координатах Unity (650, 55, 270), верхний (300, 96, 95).
- **Подвесной мост** с уступа станции (+77 м) на правое плечо гиганта. Площадка на ключице, оттуда виден череп сверху.
- **Облака** — непрозрачная поверхность без коллайдера. Под облака уходить нельзя: ниже отметки −60 м рельефа нет, поставьте kill-зону или возврат игрока на высоте Y < −40.
- **Точка старта**: перрон у ангара (верхний конец полосы), лицом к гиганту.
- По костям гиганта можно ходить (MeshCollider): от плеча вверх по ключице и шейным позвонкам.

## Обновление 7: кадр PS1
Во всех локациях теперь включён вывод как у PS1 (решение для всей игры): кадр рендерится в 240 строк и растягивается
без сглаживания, цвет 15-битный (5 бит на канал) с упорядоченным дизерингом Байера 4×4. Это блок `psx` в
`Data/AboveClouds_Look.json` (240 строк, 5 бит, дизеринг 1). Сборщик вешает `SkyIslandPSX` на камеру локации, работает в Play;
окно Capture снимает без него. На камеру игрока компонент ставится вручную: `Add Component → Sky Island → PSX Output`
(240, 5 бит, дизеринг 1), нужен Unity UI (`com.unity.ugui`, стоит по умолчанию). Кадр рисуется через RawImage на overlay-канвасе
с порядком −1000: интерфейс игры должен быть выше. Самолёт внутри локации тоже попадает в кадр 240 строк.
Текстуры этой карты переведены на рецепт самолёта в обновлении 8.
Порядок: `SkyIsland_Update6.unitypackage` → `AboveClouds_Update7.unitypackage` → пересобрать локацию в Location Builder.

## Обновление 8: текстуры по рецепту самолёта
Текстуры карты переведены на тот же PSX-рецепт, что у самолёта, Sky Island, главного корпуса базы и леса (`docs\gdd\PSX_STYLE_FOR_ENVIRONMENT.md` в проекте, код — тот же): около 64 px на метр по настоящим UV вместо прежних реалистичных 340–1000 px/м, затенение запечено в цвет, швы — тёмной линией в тексель, палитра 64 цвета на текстуру с дизерингом Байера 4×4, маски металла и гладкости `*_M_px`, блики включены, карт нормалей нет. 57 файлов `*_px.png` лежат в `Textures/` этой карты (общие текстуры ядра не меняются); импорт без фильтрации и без сжатия делает импортёр ядра. Гладкими остались: макро-текстура рельефа, разметка ВПП, море облаков, дальние вершины. Эталонные превью сняты заново с новыми текстурами (без кадра PS1, как снимает Capture).
- Кости великана (17.10): прежний PSX-атлас 512 px на скелете длиной 558 м давал 0,7 px на метр — тексель 1,4 м, а дизеринг Байера вблизи (челюсть, кисти) выглядел крупной шахматкой. Теперь у `M_Bone_Clouds` гладкий макро-атлас `T_Giant_Macro_A.jpg` (2048 px, затенение в цвете, без палитры и дизеринга; в имени `_Macro` — импортёр ядра ставит трилинейную фильтрацию и Clamp, как у макро-текстуры рельефа) и PSX-деталь кости `T_BoneDetail_A_px` с повтором 160 — около 52 px на метр на большом великане, на малых гуще. Маски нет (кость матовая, как и была), средний цвет кости прежний. `T_Giant_A_px` и `T_Giant_M_px` больше не нужны — лежат без ссылок, удалять не обязательно. Превью с великаном сняты заново.
Порядок: `AboveClouds_Update8.unitypackage` поверх → **Rebuild** в Location Builder → Capture и сверка.

## Ограничения
- Облака — освещаемая поверхность с медленно текущей текстурой (`uvScroll`) и редкими клубами пара (эмиттеры). Объёмных облаков в URP нет.
- Тени пиков на облаках видны только в пределах Shadow Distance из URP Asset. Для этой карты нужно ~2000 м и 4 каскада (см. промпт для Unity).
- Код не запускался в редакторе Unity: синтаксис C# проверен, API сверены с исходниками Unity/URP.
