# Обучающие ролики

Версия 0.1 от 22.10.2026 — черновик для обсуждения (`QUESTIONS_2.md`, вопрос 20). Ролики — главный способ рассказать лор без чтения.

Решения:
- на ПК базы — один ролик, вводный, как для нового работника;
- остальные — на компьютерах в других местах, это награда за исследование;
- каждый следующий страшнее.

Стиль: учебный фильм 1970-х программы SNOW. Вежливый диктор на немецком (озвучка переводится), бодрая музыка, рисованный талисман, плёночные царапины. Длина 1–2 минуты.

Хоррор строится на том, что в ролике есть то, чего там быть не должно: кадр, звук, фигура на фоне. При повторном просмотре этого уже нет (E25).
