# Задания

Версия 0.1 от 21.10.2026 — черновик для обсуждения. По дням — `DAYS.md`, монстры — `MONSTERS.md`, события и доставки — `EVENTS.md`.

Как приходят задания (вопрос 30): почта на ПК, рация, факс, записка. Задание называет **цель**, а не способ: «Ретранслятор не отвечает. Восстановить связь». Способ игроки ищут сами. Если долго нет прогресса, начальник звонит снова и даёт деталь (лестница подсказок, `VISION.md`, раздел 4).

Четыре вида заданий:
- **С** — сюжетные: одно главное в день, двигают акт;
- **Р** — рутина: повторяются, держат базу живой, дают немного денег;
- **П** — побочные: от начальника, необязательные, за деньги и находки;
- **И** — исследование: их никто не выдаёт, игроки находят сами.

Деньги — зарплата (вопрос 24). Суммы — после решения по экономике (`QUESTIONS_2.md`).
