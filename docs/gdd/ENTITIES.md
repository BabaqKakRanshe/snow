# Энтити (аномалии и явления)

Версия 0.2 от 21.10.2026. Энтити — явление без тела, которое можно встретить: стук, голос, предмет, который двигается сам, видение. Существа с телом — в `MONSTERS.md`. События, которые энтити запускают, — `EVENTS.md`.

Никто из них не убивает. Они пугают, мешают, подсказывают правила мира и дают клипы для стримов.

Кто видит:
- **один** — случайный игрок (вопрос 45), только когда рядом нет свидетеля;
- **группа** — все, кто рядом;
- **мир** — меняется для всех.

## Звуковой контракт

Ложные звуки бывают только у галлюцинаций (№ 1, 2), и микшируются они иначе: глуше и без направления. Остальные энтити звучат честно.
