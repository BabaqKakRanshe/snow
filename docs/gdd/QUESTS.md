# Задания — простая схема

Версия 0.1 от 23.10.2026. Основа — ответы в `QUESTIONS_3.md` и устройство Voices of the Void. Список заданий — `TASKS.md`.

## Как в Voices of the Void

1. Каждую полночь начальник (Dr. Bao) присылает письмо на компьютер. В письме задание на день: найти сигналы, снять данные с тарелок, записать ленты.
2. Отдельного списка или счётчика нет. Письмо можно перечитать в почте.
3. Всё собранное игрок кладёт в мешок дрона и отправляет.
4. Если всё сделано, приходит письмо «молодец» и очки. Не сделал — штраф.

Проблема VotV: рядом приходят другие письма, и игроки путают, какое из них засчитывает задание.

## Как у нас

1. **Утром письмо** от начальника на ПК базы: одно главное задание дня и иногда одно-два мелких. Срок пишется в письме: «до темноты» или без срока.
2. **Перечитать** — в почте на ПК. Почта и есть журнал.
3. **Выполнить.** Ремонт засчитывается сам, когда объект заработал. Данные сдаются руками: кассета в ящик на вертолётной площадке или факс с базы.
4. **«Принято. — K.»** — короткий ответ по факсу. Только он значит «готово».
5. **Застряли** — начальник звонит по рации. Сначала говорит, где искать, потом что не так, потом какое устройство.
6. **Рутина без писем.** Генератор, котёл, лампочки — не задания. Они просто ломаются, и это видно и слышно.
7. **Кооп.** Задания общие, счёт общий. Зашёл позже — появляешься на базе.

## Обучение в первый день [предложение]

Правило: каждую вещь игрок первый раз делает там, где ему ничего не грозит. Опасность — со второго раза.

| Шаг (`FOREST_OPENING.md`) | Чему учит | Как |
|---|---|---|
| S1 Машина заглохла | ходьба, выход из машины, холод | В бардачке карта, хижина обведена. Между ёлок горит фонарь хижины. Светло, тихо. |
| S2 Хижина | E, карманы, тяжёлое в руках | Мелочи на полке — попробовать взять в карман. Канистра тяжёлая — несут перед собой. |
| S3 Заправка | действие с удержанием | Воронка рядом с канистрой. Без воронки половина проливается — ошибка видна, но не страшна. |
| S4 Запуск | стартер, рукоятка | Три неудачные попытки стартером — подсказка: рукоятка лежит в багажнике. |
| S5 Дорога | вождение | Одна дорога, столбики-отражатели. |
| S6 КПП | ключи, замки | Шкафчик с ключами, на каждом бирка: «Schranke», «Generator»… |
| S7 Питание | режим осмотра, ручной насос | Бланк «порядок пуска» на пульте генератора. Насос у баков. |
| S8 Котёл | вентиль, кнопки, сброс ошибки | Красная риска на манометре на 1,5 бар. Первая ошибка STÖRUNG будет всегда — игрок учится сбросу, пока безопасно. |
| S9 Закрыть базу | засов, ставни | Табличка у двери: «На ночь — засов и ставни». |
| S10 Сон | кровать, пропуск ночи | Записка на подушке: «Утром — почта на ПК». |

Ещё:
- **Надписи на приборах** — «AUF / ZU», стрелка «RESET», риски на шкалах. Это часть мира, есть в обоих режимах.
- **Обучающие ролики** учат правилам станции, не клавишам.
- **Проверка:** дать пройти первый день 3–5 людям, которые игру не видели, и молчать. Где застряли — туда табличку или надпись, а не всплывающий текст (так делали в Valve).

## Два режима [предложение]

Сначала делаем игру, которую можно пройти по одному письму. Помощь кладём сверху.

| | С подсказками | Без подсказок |
|---|---|---|
| Письмо утром | да | да |
| Список заданий по кнопке, выполненное зачёркнуто | да | нет |
| Звонок-подсказка, если долго нет прогресса | через ~5 мин | через ~15 мин или никогда |
| Подсказка клавиш («E — взять») | всегда | только первый день |
| Игроки на карте от GPS-вышек | да | да — это часть мира |

- **Названия** (не «лёгкий» и «сложный»): «По инструкции» / «По памяти», или «Стажёр» / «Старожил», или «С бригадиром» / «Сам себе бригадир».
- **Кто выбирает:** хозяин игры, при создании сохранения.
- **Менять по ходу:** можно, только хозяину и только во сне, между днями. Ачивку «без подсказок» дают, только если так с первого дня (как в Mafia).

## MVP в игре (23.10.2026)

Что уже есть (код, не проверено в игре):
- 6 заданий первого дня: бензин → КПП → питание → отопление → закрыть базу → сон. Данные — `Forest_Tasks.json`.
- Задание засчитывается само, когда шаг сделан в мире. Сделали раньше — засчитано сразу.
- **J** — журнал смены. «По инструкции»: список и подсказки. «По памяти»: только тексты.
- Новое задание — строка вверху экрана. Подсказка — субтитр внизу через 5 мин (или 15 мин) без прогресса.
- По отоплению и закрытию базы подсказывает начальник по рации.
- Режим и проверка — дев-пульт (~) → «Задания».
- Журнал пока в старом виде — перевести на общий `Hud`, как остальной интерфейс.

Чего пока нет: писем на ПК, факса «Принято», сохранения, заданий дня 2.
