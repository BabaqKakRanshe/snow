# Холодный

Всё по Холодному. Общие правила монстров и сводная таблица — `..\..\MONSTERS.md`.

## Описание

| | |
|---|---|
| **Внешность** | Передвигается на четырёх конечностях. Руки длиннее ног, тело истощённое, бледно-серое. Голова почти голый человеческий череп: провалы глаз с тусклым светом, открытые зубы. Ползком ~3 м в длину, может подняться на задние ноги в полный рост. Референс разработчика — `refs\`; листы для модели (3 вида, голова, позы) — `model\` (26.10) |
| **Звук** | Сухой хруст суставов и короткий выдох носом. Слышно метров с 30 |
| **Когда** | Только ночью. День 1 — один раз переходит дорогу (X02). С дня 2 охотится. В метель активнее |
| **Где** | Лес, дороги, двор базы, у контейнера генератора. В тёплую освещённую базу почти не входит: редко, случайно, по решению режиссёра (E30, с дня 4) |
| **Что делает** | Идёт на шум (R2): мотор, генератор, крик, громкий голосовой чат. В метель глушит генератор (E01). Ходит параллельно ночной машине (E14). Утаскивает одиночку в лес |
| **Чего боится** | Тепла и тёплого жёлтого света (R1): натриевые лампы, костёр, освещённые окна. Группы — к троим не подходит |
| **Как реагирует на игроков** | Сначала показывается: силуэт, звук. Если игрок один и в темноте — подходит. Если на него светят жёлтым — уходит в темноту. Белый фонарик его не держит |
| **Как избежать** | Держаться вместе, ночью не шуметь, свет над генератором, натриевый прожектор вышки, не ходить по одному |
| **Утаскивание** | Игрок один, дальше ~12 м от своих и от тёплого света. Сначала предупреждение, потом захват: крик затихает, на снегу след волочения, выпадает фонарь. 60–90 с, чтобы догнать по следу. Догнали — бросает жертву. Не успели — игрок просыпается у койки замёрзшим, его вещи остаются в лесу. После пробуждения 3 минуты «замёрзший»: мычит, рация у него не работает (`QUESTIONS_HORROR.md`, вопрос 9); дрожь и Рассудок ниже до утра (вопрос 19). Вариант с возвращением своими ногами — вопросы 33–36, обсуждается |
| **Что даёт исследованию** | Правила R1 и R2. Его постоянный маршрут виден на радаре (день 6) |

## Концепты

### 1б. Холодный, вторая серия по референсу разработчика — `concept_v2\01_holodny_v2_sheet.jpg`

Решено 21.10: на четырёх конечностях, лицо почти череп (референс — `refs\ref_user.png`).

1. Через боковое окно фургона, в жёлтом свете фар.
2. Ползёт через дорогу в свете фар, вид с места водителя.
3. На крыше контейнера генератора в метель, вид из окна базы.
4. Утаскивает рабочего в лес, вид из-за спины напарника с фонарём.

### 1. Как выглядит Холодный, первая серия (вопрос 42) — `concept_v1\01_holodny_sheet.jpg`

1. Тощий белый гуманоид ~3 м, без лица, на краю света фар.
2. Худая фигура в обледеневшем рваном халате техника у контейнера генератора, вид из окна базы.
3. Сутулый силуэт ~4 м из сосулек и снежного тумана на границе жёлтого фонаря.
4. Ходячий скелет, «маленькая копия великанов», переходит дорогу.
