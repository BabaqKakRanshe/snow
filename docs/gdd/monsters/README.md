# Монстры: папки

По папке на монстра: описание (`README.md`), референсы, концепты, листы для модели, макеты. Общие правила и сводная таблица — `..\MONSTERS.md`.

| Папка | Монстр |
|---|---|
| `01_holodny\` | Холодный |
| `02_lesnik\` | Лесник |
| `03_dvoynik\` | Двойник |
| `04_olen\` | Неправильный олень |
| `05_kukla\` | Кукла |
| `06_nevesomye\` | Невесомые (акт 2) |

Подпапки внутри: `refs\` — референсы разработчика; `concept_vN\` — серии концептов (последняя — текущий вид); `model\` — листы для 3D-модели; `ingame\` — монстр, вписанный в кадры игры. Картинки генерируются через Codex (skill codex-imagegen), запрос лежит рядом с картинкой в `*_prompt_*.txt`.
