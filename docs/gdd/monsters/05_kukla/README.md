# Кукла

Общие правила монстров и сводная таблица — `..\..\MONSTERS.md`. Была энтити, перенесена в монстры 26.10.

## Описание

| | |
|---|---|
| **Внешность** | Тряпичная кукла 0,32 м сидя: красное вязаное платье, рисованное лицо, косы с красными бантами. Модель — `GEAR_CONTRACT.md`, `Item_Doll` |
| **Когда** | Приходит утром дня 3 в посылке «подарок от начальника». Открытка «— K» без точки — первый признак подмены начальника |
| **Что делает** | Двигается, только когда на неё никто не смотрит. Выброшенная возвращается. Ночью отключает генератор и сидит на рубильнике (`BASE_THREATS.md`); фейк — сидит рядом и смотрит на рубильник |
| **Опасность** | Сама не трогает. Гасит свет и тепло базы — открывает дорогу Холодному |
| **Что делать** | Включить генератор заново; унести — вернётся; сжечь в котле — скачет давление |
| **Конец демо** | Закрыли меню открытки — кукла поворачивает голову |

## Файлы

Концептов нет. Модель описана в `..\..\GEAR_CONTRACT.md`, `Item_Doll`. Кухня с куклой в красном свете — `..\..\concept\06_redmode\06_redmode_4.png`.
