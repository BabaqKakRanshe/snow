# Двойник

Всё по Двойнику. Общие правила монстров и сводная таблица — `..\..\MONSTERS.md`.

## Описание

| | |
|---|---|
| **Внешность** | Точная копия одного из игроков: та же куртка, тот же предмет в руке. Лица не видно, как и у всех рабочих |
| **Звук** | Нет. Это главный признак: настоящий игрок шуршит снегом, двойник беззвучен |
| **Когда** | С дня 2, в сумерки и ночью. Не чаще раза за вечер |
| **Кого копирует** | Игрока, которого сейчас **не видит** тот, кому показывается Двойник. Например, А внутри базы, Б во дворе — Б видит «А» на опушке. В одиночной игре (и в демо) копирует **самого игрока**: в той же куртке, с тем же предметом в руке |
| **Где** | 40–80 м от зрителя: опушка, берег озера, конец дороги в свете фар, крыша корпуса |
| **Что делает** | Стоит и медленно машет одной рукой. С каждым днём появляется немного ближе (с 80 до 40 м к дню 7) |
| **Реакция на игроков** | Идут к нему — отступает в лес, держа дистанцию. Свет фонаря — замирает. Отвели взгляд — исчезает. Помахали в ответ — перестаёт махать, поворачивается и уходит (юмор) |
| **Опасность** | Сам не нападает. Если пойти за ним в лес после темноты, он ведёт к Холодному: заманивает |
| **Кто видит** | Чаще все, кто рядом. Иногда только один игрок (личное событие) |
| **Классический момент** | Б видит «А» на опушке и говорит в голосовой чат: «Ты зачем туда пошёл?» — А отвечает из кухни |
| **Что даёт исследованию** | Правило «беззвучный — не наш». Связь с Холодным: куда он ведёт, там и гнездо |

## Концепты

### 3. Двойник (вопрос 46) — `concept_v1\03_dvoynik_sheet.jpg`

1. На опушке в сумерках; на переднем плане спины двух настоящих рабочих.
2. На том берегу замёрзшего озера, за ним кисть великана.
3. В конце дороги в свете фар, вид с места водителя.
4. На крыше корпуса машет; на переднем плане рукав игрока — такая же куртка.
