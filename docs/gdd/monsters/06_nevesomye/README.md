# Невесомые (акт 2, Sky Island)

Общие правила монстров и сводная таблица — `..\..\MONSTERS.md`.

## Описание

| | |
|---|---|
| **Внешность** | Бывший персонал острова в форме 70-х. Наглотались пыли и стали легче воздуха. Парят под потолком ангаров, привязанные ремнями к кольцам в полу |
| **Поведение** | Почти все безвредны: поворачивают головы за фонарём. Одна форма срывается с ремня и уносит игрока вверх, в туман |
| **Как спасти** | Схватить унесённого или перерезать трос |

Подробно — когда дойдём до акта 2.
