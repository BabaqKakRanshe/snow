# Название студии — вопросы

Автор: Милютин Владимир Владимирович. Ники: Babaq, BabaqKakRanshe, ProstiGospodi.

## Как делают другие (референсы)

- **Ник = студия.** ConcernedApe (Эрик Бароне, Stardew Valley), Hempuli (Арви Тейкари, Baba Is You), Puppet Combo (Бен Кокко, хоррор). Один человек — одно имя, люди запоминают автора.
- **Инициалы.** GSC Game World (S.T.A.L.K.E.R.) — инициалы основателя Сергея Григоровича.
- **Странная картинка из двух слов.** Ice-Pick Lodge (Мор), Red Barrels (Outlast), Frictional Games (Amnesia). Не про одну игру, но задаёт настроение.

## Правила (бестпрактис)

1. Короткое, легко сказать вслух и написать по слуху.
2. Не про одну игру: студия переживёт Snow (дальше метро, мегаструктура).
3. Поиск в Google по имени должен находить тебя первым.
4. Свободны: домен .com, Steam/itch, соцсети, товарный знак (WIPO, Роспатент, EUIPO).
5. Проверить, что слово не значит плохого в других языках.
6. Похожие имена тоже мешают, не только точные совпадения.
