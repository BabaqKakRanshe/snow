# Монстры

Версия 0.3 от 26.10.2026. Монстр — существо с телом: его видно, оно двигается и само решает, куда идти. Явления без тела (стуки, голоса, видения) — в `ENTITIES.md`. Кукла перенесена сюда из энтити 26.10 (решение разработчика: «тоже монстр по сути»). Правила мира R1–R6 — `VISION.md`, раздел 4. Описание, референсы и картинки каждого монстра — в его папке `monsters\<монстр>\` (с 26.10).

Общее:
- Утаскивать может только Холодный. Остальные пугают, воруют, наблюдают.
- У каждого монстра свой узнаваемый звук, и звучит он, только когда монстр рядом (звуковой контракт).
- Режиссёр говорит монстру, куда идти, но не телепортирует его на виду у игроков. Ищет монстр сам: по слуху, свету, движению.
