# Монстры

Версия 0.2 от 21.10.2026. Монстр — существо с телом: его видно, оно двигается и само решает, куда идти. Явления без тела (стуки, голоса, кукла, видения) — в `ENTITIES.md`. Правила мира R1–R6 — `VISION.md`, раздел 4. Концепты — `concept\`.

Общее:
- Утаскивать может только Холодный. Остальные пугают, воруют, наблюдают.
- У каждого монстра свой узнаваемый звук, и звучит он, только когда монстр рядом (звуковой контракт).
- Режиссёр говорит монстру, куда идти, но не телепортирует его на виду у игроков. Ищет монстр сам: по слуху, свету, движению.

## Холодный

| | |
|---|---|
| **Внешность** | Передвигается на четырёх конечностях. Руки длиннее ног, тело истощённое, бледно-серое. Голова почти голый человеческий череп: провалы глаз с тусклым светом, открытые зубы. Ползком ~3 м в длину, может подняться на задние ноги в полный рост. Референс разработчика — `concept\01_holodny_v2\ref_user.png` |
| **Звук** | Сухой хруст суставов и короткий выдох носом. Слышно метров с 30 |
| **Когда** | Только ночью. День 1 — один раз переходит дорогу (X02). С дня 2 охотится. В метель активнее |
| **Где** | Лес, дороги, двор базы, у контейнера генератора. В тёплую освещённую базу почти не входит: редко, случайно, по решению режиссёра (E30, с дня 4) |
| **Что делает** | Идёт на шум (R2): мотор, генератор, крик, громкий голосовой чат. В метель глушит генератор (E01). Ходит параллельно ночной машине (E14). Утаскивает одиночку в лес |
| **Чего боится** | Тепла и тёплого жёлтого света (R1): натриевые лампы, костёр, освещённые окна. Группы — к троим не подходит |
| **Как реагирует на игроков** | Сначала показывается: силуэт, звук. Если игрок один и в темноте — подходит. Если на него светят жёлтым — уходит в темноту. Белый фонарик его не держит |
| **Как избежать** | Держаться вместе, ночью не шуметь, свет над генератором, натриевый прожектор вышки, не ходить по одному |
| **Утаскивание** | Игрок один, дальше ~12 м от своих и от тёплого света. Сначала предупреждение, потом захват: крик затихает, на снегу след волочения, выпадает фонарь. 60–90 с, чтобы догнать по следу. Догнали — бросает жертву. Не успели — игрок просыпается у койки замёрзшим, его вещи остаются в лесу |
| **Что даёт исследованию** | Правила R1 и R2. Его постоянный маршрут виден на радаре (день 6) |

## Лесник

Решение разработчика 21.10.

| | |
|---|---|
| **Внешность** | Очень худой старик с ненормально длинными руками и ногами. Седая щетина, впалые щёки. Рваная военная зимняя одежда 70-х: оливковая парка с драными рукавами, вязаная шапка, тряпки на ботинках |
| **Звук** | Шарканье, тихое бормотание, звяканье украденного в карманах |
| **Когда** | Ночью ходит, днём спит в своей пещере |
| **Где** | Лес вокруг базы, двор, незапертые помещения. Пещера в лесу (место — `DAYS.md`) |
| **Что делает** | Ворует небольшие вещи: фонарик, батарейки, рацию, банку еды, ключ, кассету. Берёт то, что оставили снаружи или в незапертом помещении (дверь открыта, ворота гаража открыты). Уносит в пещеру. Наблюдает за игроками: прячется за деревьями, выглядывает из-за угла |
| **Чего боится** | Людей. К бодрствующему игроку ближе ~15 м не подходит (R6). Пойман фонарём — закрывается рукой и убегает |
| **Агрессия** | Нет. Не нападает и не утаскивает |
| **Как избежать кражи** | Закрывать двери и ворота, не оставлять вещи на улице |
| **Как вернуть украденное** | Днём найти пещеру и забрать, пока он спит. Если он проснётся — убежит, вещи останутся |
| **Первая ночь (X09–X11)** | Шаги в коридоре, открытая дверь казармы, следы от запертой входной двери — это он. Входная дверь была на засове, но он знает старый проход из подвала: это «другой вход» из гипотезы игроков. Пока проход не найден и не закрыт, база для него открыта |
| **Что даёт исследованию** | Пещера — тайник украденного, там же ключ «Stationsleiter» и вещи 1991 года. Правило R6 |

## Двойник

| | |
|---|---|
| **Внешность** | Точная копия одного из игроков: та же куртка, тот же предмет в руке. Лица не видно, как и у всех рабочих |
| **Звук** | Нет. Это главный признак: настоящий игрок шуршит снегом, двойник беззвучен |
| **Когда** | С дня 2, в сумерки и ночью. Не чаще раза за вечер |
| **Кого копирует** | Игрока, которого сейчас **не видит** тот, кому показывается Двойник. Например, А внутри базы, Б во дворе — Б видит «А» на опушке. В одиночной игре (и в демо) копирует **самого игрока**: в той же куртке, с тем же предметом в руке |
| **Где** | 40–80 м от зрителя: опушка, берег озера, конец дороги в свете фар, крыша корпуса |
| **Что делает** | Стоит и медленно машет одной рукой. С каждым днём появляется немного ближе (с 80 до 40 м к дню 7) |
| **Реакция на игроков** | Идут к нему — отступает в лес, держа дистанцию. Свет фонаря — замирает. Отвели взгляд — исчезает. Помахали в ответ — перестаёт махать, поворачивается и уходит (юмор) |
| **Опасность** | Сам не нападает. Если пойти за ним в лес после темноты, он ведёт к Холодному: заманивает |
| **Кто видит** | Чаще все, кто рядом. Иногда только один игрок (личное событие) |
| **Классический момент** | Б видит «А» на опушке и говорит в голосовой чат: «Ты зачем туда пошёл?» — А отвечает из кухни |
| **Что даёт исследованию** | Правило «беззвучный — не наш». Связь с Холодным: куда он ведёт, там и гнездо |

## Неправильный олень

| | |
|---|---|
| **Внешность** | Обычный благородный олень, только ног на одну больше. Двигается плавно, не по-оленьи |
| **Когда, где** | Ночью на дороге, с дня 2, раз в несколько ночей |
| **Что делает** | Стоит в свете фар и смотрит, не убегает |
| **Реакция** | Объехали — смотрит вслед. Сбили — машина глохнет (R3), оленя на дороге нет |
| **Опасность** | Только через машину: заглохнуть ночью в лесу |

## Невесомые (акт 2, Sky Island)

| | |
|---|---|
