## 1. Схема системы [предложение]

```
              ┌──────────────── хост ────────────────┐
  игроки ──►  │ 1. Шкалы игроков                     │
 (позиция,    │    Страх (быстрый), Рассудок (медл.)  │
  свет, звук, │              │                       │
  голос)      │              ▼                       │
              │ 2. Режиссёр: фаза + профиль ночи     │──► 5. Лог сессии (JSONL)
              │    бюджет, расписание, милосердие    │
              │              │                       │
              │              ▼                       │
              │ 3. Выбор события по таблице          │──► F1: оверлей режиссёра
              │    (условия, веса, кто видит)        │
              │              │                       │
              │      ┌───────┴────────┐              │
              │      ▼                ▼              │
              │ 4а. Событие-рецепт  4б. Поводок      │
              │  (звук/свет/фейк)   монстра          │
              └──────┬─────────────────┬─────────────┘
                     ▼                 ▼
           всем / группе / одному   Холодный, Лесник, Двойник
           (RPC целевому клиенту)   — ищут сами: слух, свет, движение
```

Режиссёр **не пугает сам**. Он решает, какое событие разрешено и когда; пугают события и монстры. Монстр слушает свои чувства, режиссёр двигает только ручки его «поводка» (§5).

### 1.1 Шкалы игрока — две, а не одна [предложение]

| | Страх | Рассудок |
|---|---|---|
| Скорость | секунды–минуты | часы игры, через ночи |
| Аналог | интенсивность L4D/Vermintide (A §2.1) | рассудок Don't Starve Together (B §2.1), Phasmophobia |
| Растёт от | увидел или услышал Холодного; рядом утащили напарника; темнота; один дальше 40 м; событие уровня «угроза» | долго в темноте и тумане (R5), не спал (E24), холод, утащили тебя или напарника |
| Падает | 2 в секунду через 3 с без новых причин; быстрее у тепла и света; **не падает, пока угроза рядом** | сон, тепло, еда, кофе, свет базы |
| На что влияет | **фаза режиссёра** (темп) | **лестница личных событий** (что тебе может померещиться) |
| Как видно игроку | дыхание, сердце, дрожь камеры — 3 уровня | обесцвечивание PSX-постэффектом, шёпот, ложные мелочи — 3–4 уровня |

Зачем две: Страх — «что сейчас», он делает пики и отдых. Рассудок — «как ты вообще», он копит историю и даёт галлюцинации только тем, кто их заработал. Это уже есть в документах кусками (R5 туман, E24 недосып) — шкала их собирает.

Правила для обеих (B §2.4, C §1.2):
- **Цифр на экране нет.** Только тело персонажа и картинка.
- **Механических штрафов нет** (медленнее бег, слабее руки) — у Amnesia от этого игра становилась непроходимой.
- Пороги с **гистерезисом**: вошёл в уровень на 50, вышел на 52,5 (DST). Иначе эффекты мигают.

Стартовые числа Страха (по Vermintide, A §2.1, приведено к нашим причинам):

| Причина | Страх |
|---|---|
| увидел Холодного (первый раз за ночь) | +40 |
| увидел Холодного снова / услышал его хруст | +15 / +10 |
| утащили напарника на твоих глазах / в радиусе слышимости | +50 / +25 |
| утащили тебя | в максимум |
| событие «угроза» / «странность» рядом | +20 / +8 |
| темнота (каждые 10 с вне света) | +2 |
| один дальше 40 м от своих (каждые 10 с) | +2 |
| рядом испуганный напарник (его дыхание слышно) | +1 в 5 с — заражение (B §3.1) |
| спад | 2/с через 3 с; ×2 в тёплом свете; ×3 на базе |

### 1.2 Напряжение группы и фазы [предложение]

Фазы — по Darktide (A §3.1), у каждой белый список категорий. Категории событий у нас уже есть в `EVENTS.md`: **О** ожидание, **С** странность, **У** угроза, плюс Холодный отдельным каналом, плюс сюжет.

| Фаза | Вход | Длится | Разрешено | Холодный |
|---|---|---|---|---|
| **Тишина** | старт ночи, конец отдыха | пока напряжение < 10 | О | не охотится |
| **Нарастание** | напряжение ≥ 10 | до 60 | О, С | подходит, показывается |
| **Пик** | напряжение ≥ 60 (соло 45) | 12–15 с, напряжение не падает | только Холодный и уже начатое | охотится, может утащить |
| **Спад** | после пика | пока напряжение > 30 и не меньше 30 с | ничего нового | уходит |
| **Отдых** | спад закончился, или все на базе | 65–100 с, на базе — пока там | О, сюжет, юмор | не охотится |

- Отдых на базе — пока игроки внутри в тепле и свете; режиссёр почти молчит (как и решено в `VISION.md` §5). Исключение — редкий E30, он проходит отдельным каналом, как босс у L4D.
- **Милосердие** (Darktide A §3.4): кого-то утащили → напряжение в максимум → обычный путь пик → спад → отдых. Выжившие получают передышку на поиск по следу.
- **Холодный глушит остальных** (Darktide A §3.5): пока он охотится, события С и У молчат 50 с. Ни одного «Лампового» во время погони.
- **Рампа** (Darktide A §3.3): если за ночь никого не утащили и никто не боялся (напряжение не выше 30), частота событий растёт ×1,5 за 20 минут. Защита от «пересидели на кухне». Сбрасывается после пика.
- **Резинка** (Lethal Company A §5.1): две тихие ночи подряд → в третью минимум одно событие С обязательно.

### 1.3 Профили ночи — наборы чисел [предложение]

Как режимы L4D2 (A §4.1): один код, разные таблицы.

| Профиль | Чем отличается |
|---|---|
| **Обычная ночь** | числа выше |
| **Метель** (E10) | порог пика ниже (50), Холодный активнее, рация шипит, события звука дальше |
| **Тихая ночь** | только О; «пустые» карты в расписании ×2. Нужна для ≥30% тихих ночей (`VISION.md` §5) |
| **Соло** (демо) | спад Страха ×1,5, рост Рассудка ×0,5, утаскивание только после двух предупреждений, личные события всегда (свидетелей нет) |
| **День** | только О и сюжет; Холодный спит |
| **Сюжетная ночь** (ночь 2 демо, ночь 7) | расписание задано руками, генератор заполняет только пустые слоты |

### 1.4 Расписание ночи — заранее, а не каждую секунду [предложение]

По Vermintide (A §2.6): в начале ночи режиссёр раскладывает слоты.
- Слот каждые 4–6 минут реального времени; первые 3 минуты после выхода с базы — безопасные.
- В слоте одна карта: **событие У / событие С / наблюдатель / пусто**. Одна и та же карта подряд не выпадает.
- Максимум **одно событие У и одно утаскивание** за ночь (обычная), два — метель.
- **Авторская сцена главнее** (PeakDelayer, A §2.7): за 100 с до и 60 с после сцены из `FOREST_OPENING.md` (X01–X11), сюжетного пика или признака подмены начальника генератор молчит.
- Карта не обязана сработать: если в момент слота фаза не та (например, отдых), карта ждёт или сгорает.

### 1.5 Бюджет по категориям [предложение]

Как challenge rating Darktide (A §3.2) + power level Lethal Company. У каждого активного события и монстра есть цена: мелкое О — 1, С — 3, У — 6, Холодный на охоте — 10 (числа уже в `VISION.md` §5). У каждой категории свой потолок: новое С не запускается, если сумма активного > 6; новое У — если > 3. Плюс **разнообразие**: не больше 4 разных событий за ночь (Lethal, A §5.1), чтобы ночь запоминалась, а не мельтешила.

## 2. Событие — рецепт из слоёв [предложение]

По Dead Space Remake (A §1): одно событие = несколько слоёв, каждый можно переиспользовать.

```
пример: «кто-то у генератора» (E01+E02)
  1. звук   — генератор кашляет (5 с)
  2. свет   — лампы двора мигают
  3. погода — порыв метели, видимость падает
  4. исход  — (а) генератор глохнет, у контейнера фигура в окне
              (б) генератор прокашлялся и работает — фейк
              (в) генератор глохнет, никого — топливо
```
Выбор исхода — по фазе и бюджету. **Фейковые исходы — штатная часть пула**, не исключение: игрок не знает, какое из трёх его ждёт (тот же принцип, что VotV в `RESEARCH_HORROR.md` §1.9).

### 2.1 Уровни испуга

По Стивену Кингу (C §1.1): ужас ожидания → ужас увиденного → отвращение. У нас это совпадает с О / С / У.

Стартовые пропорции на сессию 30–60 минут (C §1.4, источников с числами нет — это ориентир):
- фон О — постоянно, каждые 1–3 минуты что-то мелкое;
- 3–5 событий С на одну встречу У;
- после любого У — минимум один полный отдых без С и У;
- **скример** (внезапный громкий показ) — только в сюжетных местах, 1–2 за демо. Frictional сократили десяток до пары и стало страшнее (C §1.2);
- после ложного разгона (фейка) — **минуты тишины** (Until Dawn, C §1.3).

### 2.2 Таблица событий — по схеме правил откликов Valve [предложение]

Valve выбирает реплики персонажей так (C §4.1, проверено по коду): у правила список условий с весами; счёт = сумма весов совпавших; если не совпало условие с пометкой `required` — правило выбывает; при равенстве — случайно. Правило может записать **факт** в память (`applyContext`) — потом другие правила его читают. У группы вариантов — мешок без повторов.

Для Snow это ложится на то, что уже есть в `EVENTS.md` («условие → эффект → кто видит → повтор»), добавляются колонки:

| Поле | Пример | Зачем |
|---|---|---|
| `id`, `category` | E06, С | |
| `require` | ночь; засов опущен; все в корпусе | обязательные условия |
| `prefer` + веса | метель +2; игрок один +1; день ≥4 +1 | что делает событие уместнее |
| `phases` | Нарастание | белый список фазы |
| `cost` | 3 | бюджет |
| `who` | мир / группа / один | |
| `witness` | `cancel` / `ignore` / `needs-empty-look` | правило свидетеля (§3) |
| `layers` | звук, свет, исход-фейк | рецепт |
| `cooldown` | 1 ночь; на игрока 2 ночи | повтор |
| `once` | да / нет | `matchonce` |
| `sets` | `generator_was_killed=1` | записать факт |
| `variants` | 3 звука стука | мешок без повторов; вес ×0,5 после каждого выбора (Sonancia, A §8.2) |

Хранить как JSON рядом с `Forest_Opening.json` — тот же формат, что уже у карты, перезагружается без рестарта (§6).

### 2.3 Варианты ярусами

Blacklist (C §4.2): первые 1–2 раза — уникальная анимация и звук, потом общие. Для Холодного: первая встреча — особый звук и поза; к десятой встрече — обычный хруст. Запоминающееся не повторяется.

## 3. Кооп: не дать страху раствориться [предложение]

Главная проблема (B §1): с друзьями смешно и безопасно. Что реально работает у других:

1. **Разделение заложено в задания, а не в просьбу.** Lethal Company: улетел корабль без живых — потерян весь лом. Outlast Trials: задачи в разных концах. У нас уже есть «ремонт вдвоём, остальные со светом» (день 3); нужно, чтобы **каждое** ночное задание имело причину разойтись.
2. **Связь — физический предмет.** Рация с батареей и дальностью (Lethal Company), гарнитура ~350 м (Barotrauma). GTFO с безлимитным голосом критикуют: «needs more fear». У нас уже голос по расстоянию + рация — нужны **дальность рации, помехи на краю и батарея**.
3. **Мёртвые молчат.** В Lethal Company и Phasmophobia голос мёртвого обрывается без предупреждения; Phasmophobia отдельным патчем закрыла утечки (свет и журнал мёртвого). У нас утащенный просыпается **живым на базе** — если он сразу заговорит в рацию, одиночество оставшихся ломается. Предложение: **3 минуты оглушения** — персонаж мычит, рация у него не работает, «замёрз» (вопрос 9).
4. **Неизвестность о товарище** (B §1.2): «no way to know if they're alive or dead». Если утащенный молчит, остальные не знают — жив ли он, на базе ли, или это Двойник машет с опушки.
5. **Смерть товарища бьёт по всем** (Phasmo −15%): утащили — Рассудок −15 у тех, кто слышал крик.
6. **Заражение страхом** (Darkest Dungeon, B §3.1): испуганный персонаж тяжело дышит — это слышно рядом и чуть поднимает Страх соседей. Обратное тоже: спокойный напарник рядом ускоряет спад. Голос игрока не анализируем — только звуки тела персонажа.
7. **Не симулировать паранойю** (The Thing 2002, B §3.2): системное «доверие» разработчики свели к паре скриптов. Нам — авторские личные события поверх простой шкалы.

### 3.1 Личные события и свидетель

Решено (вопрос 45): видит случайный игрок, только без свидетеля. Добавляется из исследования:
- **Проверка действием** (патент Eternal Darkness, B §2.2): у каждого личного события есть способ его «разоблачить» — посветить, посмотреть второй раз, позвать по рации. После проверки явление пропадает. Игрок, который проверил, чувствует себя умным, а не обманутым.
- **Свидетель как проверка реальности** (The Mound 2026, B §2.1): «ты видишь фигуру у сарая?» — «нет» — это и есть ответ. Работает, только если события строго не показываются при свидетеле.
- **Кто свидетель** — по карте видимости (Warframe, C §4.4): хост знает направления камер всех игроков; зона, которую игрок видел последние 3 с, считается «под взглядом».
- **Отличимость.** Ложные звуки — другим микшированием (уже решено). Плюс: личные события никогда не используют **сигнатурные звуки** Холодного — его хруст всегда настоящий (C §2.3).
- **Лестница Рассудка** (DST, B §2.1): сверху — косметика и звук (шёпот, тень на краю зрения), ниже — ложные предметы и «напарник выглядит иначе», в самом низу — Бессонник (E24). Угроза — только внизу лестницы.

### 3.2 Смерть без фрустрации

Решено: утащенный просыпается у койки, вещи остаются в лесу. Из исследования (B §4): это и есть «вылазка за телом» Lethal Company и R.E.P.O. — хорошая история, если:
- место вещей отмечено **следом** (уже есть: волокуша, выпавший фонарь);
- вещи лежат у «гнезда» — его ищут днём, это задание, а не потеря;
- при пробуждении — **шрам**: Рассудок ниже, персонаж дрожит до утра (как 1 HP в R.E.P.O.). Без штрафов к цифрам.

## 4. Звук и свет [предложение]

- **Источники страха** (Dead Space, Don Veca, C §2.1): у Холодного и опасных мест есть сфера, которая подмешивает 4 слоя музыки, эмбиент и реверберацию. Но включается это **только по восприятию игрока** — видел или слышал (C §2.3). Если игрок не знает о Холодном, музыка молчит.
- **Тишина как инструмент** (C §2.4): перед сильным событием на 5–10 с стихает эмбиент. Игроки научатся бояться тишины — это и есть бомба Хичкока.
- **Звук до угрозы, а не на ней** (Sonancia, A §8.2): тревожные звуки ставятся там, где монстра **нет**. Где он есть — его честный хруст.
- **Свет квантуем до 3 уровней** (C §3): тёплый свет / белый свет / темнота. Холодный видит только по ним, игрок видит уровень по миру (лампа, фонарь, тень). Иначе современный свет «нечитаем» для правил R1 (Хокинг, C §3). После работы над тёмной ночью леса (22.10) это следующий шаг: темнота должна стать правилом, а не только картинкой.

## 5. Холодный — простой автомат и поводок режиссёра [предложение]

Сложный ИИ игроки не отличают от простого (C §5.3). Предлагаю иерархический автомат на 5 состояний:

| Состояние | Что делает | Выход |
|---|---|---|
| **Бродит** | ходит по точкам у дорог и опушек, вне видимости игроков | услышал шум (R2) → Слушает |
| **Слушает** | стоит, поворачивает голову к звуку; показывается издалека | шум повторился → Идёт на звук; тишина 20 с → Бродит |
| **Подходит** | идёт к источнику шума, держится темноты; хруст слышно с 30 м | увидел одиночку вне света → Охота; жёлтый свет → Уходит |
| **Охота** | предупреждение (звук, силуэт), потом захват | схватил → утаскивание; догнали/свет → Уходит |
| **Уходит** | отходит в темноту за пределы видимости | через 60–120 с → Бродит |

Чувства (C §5.1): реакция 0,2–0,4 с; зрение — 1–2 с до «заметил» в центре конуса, движение +0,3, темнота −0,3 к уверенности; слух — по зонам через двери (на базе) и по прямой с затуханием в лесу; вне экрана у игроков слух ×0,5 (Blacklist: «сразу стало веселее»). После потери цели он «знает» её позицию ещё 2–3 с, потом ищет от последней известной точки.

**Поводок** — ручки, которые двигает режиссёр, никогда не трогая позицию монстра на виду:
1. вес настоящей позиции игрока при выборе точек поиска: 0 в отдыхе, 0,3 на пике;
2. множители слуха и зрения по фазе;
3. появление и перемещение — только в зонах, которые **никто** из игроков не видел последние 3 с (карта видимости);
4. приказ «уйти»: после утаскивания, после пика, если группа ≥ 3 человек вместе (уже в `MONSTERS.md`);
5. триггер утаскивания — **одиночество**: игрок дальше 12 м от своих и от тёплого света (уже решено) **и** формула Vermintide `sqrt(Σd²)/N` выше порога **и** фаза Пик. В соло — только Пик и два предупреждения.

## 6. Инструменты — без них режиссёра не настроить [предложение]

По Valve `rr_debugrule`, Warframe, Blacklist (C §4.4–4.7). В F1-меню (`SnowCheatMenu`):

1. **Оверлей режиссёра**: график напряжения и Страха каждого игрока за 10 минут, фаза цветом, отметки сработавших событий.
2. **Топ-5 кандидатов**: какое событие хотело сработать и **почему нет** (кулдаун, бюджет, фаза, свидетель).
3. **Мини-карта**: Холодный, его состояние и цель, последняя известная ему позиция игроков, карта видимости.
4. **Ручки**: запустить событие на себя / на игрока N / на всех; заморозить фазу; выставить напряжение; время ×4 и ×8; фиксированный сид; перезагрузить таблицу событий без рестарта.
5. **Лог сессии** на хосте — одна строка JSON на событие: время, фаза, напряжение, Страх каждого, событие, кто видел, позиции, состояние Холодного. Расширение уже существующего `BenchLog`.

### 6.1 Плейтест хоррора (C §4.6)

- Кооп 2–4 человека (так честнее и есть естественные реплики); писать экран и голосовой чат.
- **Не просить думать вслух** — это убивает присутствие.
- После сессии каждый рисует **кривую страха** на таймлайне с метками событий из лога.
- Испуг рабочий, если пик совпал **у двух и более** игроков (Until Dawn).
- На каждое событие — «сработало / не заметили / раздражало».
- Тестеры свежие: испуг гаснет с каждым прогоном.
- Биодатчики соло-разработчику не нужны; у Valve главный урок биофидбэка — положительная обратная связь (страх сам себя разгоняет) лечится спадом шкалы. Спад у нас есть.

## 7. Порядок работ [предложение, ждёт вопроса 2.35]

Каждый шаг можно проверить отдельно:

1. **Шкалы + лог + оверлей** — без событий. Видно, как Страх растёт и падает от темноты и одиночества.
2. **Фазы + профили** — автомат режиссёра, переключение на базе в Отдых.
3. **Таблица событий** с 5–6 событиями из `EVENTS.md`, которые не требуют монстра: E06 (датчик окна), E09 (микроволновка), E12 (голос повторяет фразу), E01/E02 (генератор, рецепт со слоями), Стучащий.
4. **Холодный** — автомат на 5 состояний + поводок.
5. **Личные события + свидетель + Рассудок.**
6. Перевод X01–X11 из `ForestOpening` в авторские сцены, которые уважает PeakDelayer (сейчас они — код в `ForestOpening.cs`, режиссёра нет).
