## 2. Как делают другие

- **Unity Audio Profiler** (окно Profiler → Audio → Detailed → Channels): колонки Object, Asset (клип), Volume, Audibility (что реально слышно после микшера), Plays (сколько раз играл), 3D, Paused, Muted, **Virtual**, OneShot, Looped, Distance, MinDist, MaxDist, Time, Duration. Сверху: играющих источников, голосов, CPU, память. Только в редакторе, не в игре. [docs.unity.com](https://docs.unity.com/en-us/engine/6000.0/manual/audio/profiler)
- **Unreal Audio Insights** (UE 5.4+), вкладка Sounds: список по категориям, Amp (Peak), Volume, Pitch, Distance, затухание, Priority, фильтры, имя актёра; mute/solo; график параметра за 5 с; вкладка Virtual Loops рисует сферу в мире у «виртуального» звука. [Epic docs](https://dev.epicgames.com/documentation/unreal-engine/sounds-virtual-loops-and-plots-in-audio-insights-in-unreal-engine)
- **Unreal консоль**: `au.Debug.Sounds` — список играющих поверх экрана, сортировка по имени / громкости / дистанции / приоритету / времени, предел 32 строки; `au.Debug.SoundWaves`, `au.DumpActiveSounds`. [Epic docs](https://dev.epicgames.com/documentation/unreal-engine/audio-console-commands-in-unreal-engine)
- **CRYENGINE** `s_DrawDebug`: флаги складываются — сферы у звучащих объектов, их имена, состояния, список. [CRYENGINE docs](https://www.cryengine.com/docs/static/engines/cryengine-5/categories/23756816/pages/36867762)
- **Wwise Profiler**: число голосов, активные шины, Voices Graph (живое дерево звуков), Voice Monitor — громкость голосов во времени, клик по ленте показывает уровень в прошлом. [Audiokinetic](https://www.audiokinetic.com/profiling-troubleshooting-and-debugging-using-wwise)
- **FMOD Studio Profiler**: подключение к игре вживую, графики голосов и экземпляров (с виртуальными), лента жизни каждого звука. [fmod.com](https://www.fmod.com/docs/2.03/studio/profiling.html)
- **Asset Store**: готового оверлея «что играет» в игре не нашёл; Audio Sync — старый список источников (2018). Проще своё.

**Общее у всех:** список (имя, источник, шина, громкость, дистанция, 2D/3D, приоритет, виртуальный ли), счётчик голосов против лимита, метр общего уровня, сортировка и фильтр, «заморозить», лог последних разовых звуков, сферы с подписями в мире.

## 3. Простейшая рабочая версия F2

**Что собрать (только на своём компьютере, по сети ничего не шлём):**
1. **Журнал в `SnowAudio`.** В `Play()` для каждой колонки пула запомнить: id cue, шину, время старта, «сервер/локально». Плюс кольцевой буфер последних 30 разовых звуков. Петли `SoundLoop` при создании кладут себя в статический список.
2. **Общий поиск раз в 1 с:** `FindObjectsByType<AudioSource>` — ловит всё остальное (рация, карманы, самолёт, `PlayClipAtPoint`). Помечать как «вне библиотеки».
3. **Громкость** — три числа:
   - «задано» = `source.volume` (уже с шиной);
   - «слышно» ≈ задано × затухание по расстоянию. Затухание у нас везде линейное (`SnowAudio.cs:116`), считается в одну строку: `1 − (d − min)/(max − min)`, с учётом `spatialBlend`;
   - **реальный уровень** = `source.GetOutputData` (кусок звука на выходе колонки) → RMS (средняя громкость) → дБ: `20·log10(rms)`. Не уверен, входит ли туда затухание по расстоянию — проверить на месте.
4. **Общий метр:** `AudioListener.GetOutputData` по 2 каналам, 1024 отсчёта (~21 мс) → RMS и пик в дБ. Это то, что реально в ушах. Метр «по шинам» без AudioMixer честно не получить; сумма по колонкам шины — приблизительно.
5. **Виртуальность:** `source.isVirtual` — Unity заглушил из-за лимита 32.

## 4. Дополнения по желанию

- Сферы в мире у звучащих колонок с подписью cue (размер = громкость, серым — виртуальные), как в CRYENGINE/Unreal.
- Кнопки mute/solo по шине и по одному cue (как в Audio Insights).
- Сортировка и фильтр по шине, по тексту id.
- Метр громкости в LUFS за минуту (по формуле BS.1770) — сверка с целью −24 LUFS ±2 (Sony, консоли) или −18 (портативные). Пока достаточно RMS.
- Показ шума для существ: последние `NoiseEvents.Emit` (радиус, кто) — полезно для монстров.
- Когда будет музыка: строка «состояние / опасность / громкость слоёв».
- Перейти на настоящий AudioMixer (`RESEARCH_AUDIO.md` §4.3): тогда «Audibility» видна в Unity Profiler, а F2 читает громкость групп.
- Писать обрывы пула и виртуальные звуки в `BenchLog` для прогонов `snow_qa`.
