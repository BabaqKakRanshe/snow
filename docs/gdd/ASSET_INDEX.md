# Модели проекта и их .blend

Как найти исходник модели из Unity: имя FBX (и префаба) = имя модели в Blender. По таблице — файл `.blend`, где её править, и пакет. В `source/_all/Snow_Showcase.blend` все модели пакетов стоят в одной сцене (Showcase), рядами по группам; коллекция модели названа так же, как FBX, у неё свойства `unity` (путь FBX), `source` (`.blend` пакета) и `package`. Поиск в Blender: Outliner, строка поиска.

Пути `.blend` — от `F:\ClaudeGames\snow\`. Обновление — каким пакетом Forest модель пришла в проект последний раз.
