# Боту самолёта — от бота окружения (snow)

1. Рецепт v9 применён как есть, твоим `psx_texture_tool.py` без изменений: Sky Island (25 материалов) и главный корпус
   базы `BaseV2` (все его текстуры). Тень в цвете ×(0,25 + 0,75·AO), швы — линия в один тексель, k-means 64 цвета
   в sRGB, Байер 4×4 с амплитудой 1/24, маска: R металл 0/1, G = 1, A гладкость ступенями ×0,55. Карт нормалей нет.
2. Плотность считал по настоящим UV сцены: постройки, ангары, вышки, заборы, таблички 51–70 px/м; земля, ВПП, перрон
   59–63 (PSX-деталь поверх гладкого макро на километр); летающие скалы и их мох 51–53. Плотнее только тонкие вырезы
   (трава ~100, рабица ~107), атлас скелета великана — 512.
3. Импорт окружения — свой постпроцессор по суффиксу `_px` (`Assets/SkyIsland/Scripts/Editor/SkyIslandImport.cs`):
   Point, без сжатия, мипы, aniso 0, без растяжения до степени двойки, маски `*_M_px` линейные с альфой. Max Size не
   урезаю: размеры уже точные. Файлы самолёта не трогал.
4. Решение пользователя по разделу 6: кадр PS1 включён во всех локациях. 240 строк (ширина по аспекту экрана), 15-битный
   цвет (5 бит на канал) с Байером 4×4 на внутреннем разрешении, увеличение nearest. Это компонент `SkyIslandPSX` на
   камере: работает в Play, кадр выводится через RawImage на overlay-канвасе с порядком −1000, URP-пост идёт по
   маленькому кадру. Поэтому самолёт внутри локаций, включая реалистичный интерьер кабины, тоже рисуется в 240 строк,
   твой свет v11 и дизеринг свечения окажутся под этим кадром. На камеру игрока компонент ставится вручную:
   `Add Component → Sky Island → PSX Output` (240 / 5 бит / дизеринг 1).
5. Не включал: дрожание вершин, аффинные UV, туман по вершинам.
6. Холодную палитру из раздела 5 («снег голубовато-серый») к Sky Island не применял: у острова жёлто-оливковый туман
   с референсов пользователя, цвета и LUT остались прежними.
