# Управление — раскладка (TEMPORARY, O-01)

Все клавиши заданы в одном файле: `Assets/Snow/Input/SnowControls.inputactions`. Код клавиш не хранит.
Подсказки в игре (карточка H, названия в подсказке) берут название клавиши из этого файла, поэтому после смены клавиши они обновятся сами.

## Как поменять клавишу

1. В окне Project дважды щёлкните `Assets/Snow/Input/SnowControls.inputactions`: откроется окно Input Actions.
2. Слева выберите карту: **OnFoot** — пешком, **Seat** — в кресле, **Cursor** — свободный курсор (Tab в кресле).
3. В середине раскройте действие, например **Reveal**, и выберите его привязку (строка с клавишей).
4. Справа в поле **Path** нажмите кнопку **Listen** и нажмите нужную клавишу. Либо выберите клавишу из списка.
5. Нажмите **Save Asset** вверху окна (или включите Auto-Save).

Правило: внутри одной карты одна клавиша — одно действие. Это проверяет тест `InputBindingsTests`. Между картами клавиши могут совпадать: например, E пешком — «использовать», а в кресле — педаль. Карты OnFoot и Seat никогда не включены одновременно.

## Пешком (OnFoot)

| Действие | Клавиша | Что делает |
|---|---|---|
| Move | W A S D | ходьба |
| Look | мышь | обзор |
| Jump | Space | прыжок |
| Crouch | Left Ctrl | присесть |
| Sprint | Left Shift | бег |
| Walk | X | медленный шаг (был Alt) |
| Use | E | использовать; держать на ящике — нести |
| Secure | R | закрепить / открепить ящик |
| Zoom | ПКМ (держать) | приближение |
| Reveal | **B** (держать) | показать всё, с чем можно взаимодействовать. **Временно B**: Alt в редакторе Unity перехватывается (открывает меню окна). В собранной игре можно вернуть Alt |

## В кресле (Seat)

| Действие | Клавиша | Что делает |
|---|---|---|
| Pitch | W / S | штурвал от себя / на себя |
| Roll | A / D | крен |
| Yaw | Q / E | педали (и руление хвостовым колесом) |
| Throttle | Left Shift / Left Ctrl | газ больше / меньше |
| Brake | Space | тормоза (педаль Q/E делает их раздельными) |
| Trim | [ / ] | триммер руля высоты: на пикирование / на кабрирование |
| Autopilot | Z | автопилот вкл/выкл (только левое кресло) |
| UseExit | F | коротко — использовать; держать 0.4 с — выйти |
| CursorToggle | Tab | свободный курсор / обзор мышью |
| Zoom | ПКМ (держать) | приближение |
| Reveal | **B** (держать) | показать интерактивное (см. выше) |
| Look | мышь | обзор головой |

## Курсор (Cursor, после Tab в кресле)

| Действие | Клавиша | Что делает |
|---|---|---|
| Point | мышь | курсор |
| Click | ЛКМ | нажать тумблер (держать — для стартера и теста ламп) |

## Не в файле раскладки (инструменты разработчика)

| Клавиша | Что делает |
|---|---|
| H | карточка-подсказка в кресле (чек-лист запуска) |
| F9 | панель погоды (только хост) |
| F10 | телеметрия разработчика |
